# 📱 App Lista de Compras

Aplicativo de lista de compras desenvolvido em Flutter, permitindo criar listas, adicionar itens, marcar como comprados e acompanhar o progresso e valores em tempo real.

## 🚀 Funcionalidades
- ✅ Criar listas de compras  
- 📝 Adicionar itens com nome e preço  
- ✔️ Marcar e desmarcar itens  
- 💰 Cálculo automático de valores:  
  - Itens marcados  
  - Itens não marcados  
- 📊 Barra de progresso baseada nos itens concluídos  
- 🔄 Botão "Atualizar" para limpar itens marcados  
- 📱 Interface moderna e responsiva  
- 📌 Uso de Bottom Sheet para adicionar itens  

## 🧠 Conceitos utilizados
- Stateful Widgets  
- Gerenciamento de estado com `setState`  
- Navegação entre telas (`Navigator`)  
- Componentização  
- Formulários e validação (`Form`, `GlobalKey`)  
- `ListView` dinâmica  
- Modal Bottom Sheet  
- Organização em Models  


## 🛠️ Tecnologias
- [Flutter](https://flutter.dev/)  
- [Dart](https://dart.dev/)
